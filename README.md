# Czack Framework 26s3.1 - Lua Zombie Escape 2D (LZE2D)

本專案為 **CSO Studio 殭屍大逃殺 2D (Lua Zombie Escape 2D)** 的官方標準範本地圖與核心框架。
提供完整的模式底層架構、UI 渲染與系統邏輯，旨在供所有地圖創作者直接作為範本建立自己的逃跑地圖。

---

## 🛠️ 地圖創作者使用指南 (Quick Start)

本專案為開箱即用的**完整範本架構**，創作者在製作自己的地圖時，請遵循以下規範：

### 1. 參數設定（唯一需要調整的檔案）
* 所有關卡規則、數值平衡、遊戲設定請統一在 **`settings.lua`** 中進行修改。
* 檔案內皆有對應的參數註解，請依需求自訂數值。

### 2. 底層核心（請勿修改）
* 包含 `common.lua`、`game.lua`、`system.lua` 及 `ui.*.lua` 等模組為框架核心，**無需也不建議進行任何更動**，以免引發系統衝突或崩潰。

### 3. 地圖建置
* 請直接基於本範本地圖進行地形建造、路徑規劃、機關與實體物件配置。
